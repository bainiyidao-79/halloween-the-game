Items decide who survives the night. Escape objectives need them, and the right pocket item can turn Michael's grab into his mistake.

## Escape items (fuel the exit objectives)

| Item | Used for | Notes |
|------|----------|-------|
| Repair kit | Fix the car, restore broken radios/power lines | Consumed on use |
| Gas can | Fuel the car escape | Combine with the sedan key |
| Sedan / car key | Start the car escape | You must drive out of town — you escape by driving, not just entering |
| Escape key | Opens certain escape points | |
| Bolt cutters | Open gated exits | **Reusable** — the best gate item |
| Padlock key | Alternative to bolt cutters on gated exits | One key is enough |

## Anti-grab saves (your second life)

| Item | Effect | Uses |
|------|--------|------|
| Butterfly knife | Escape Michael's grab | One time |
| Ice pick | Escape Michael's grab | One time |
| Amulet | Automatically saves you when grabbed or hit | Pops once |

Grab-escape items work like a one-time decisive strike: use them the moment he grabs you, then find a new one.

## Utility items

| Item | Effect |
|------|--------|
| Brass lantern | Slows Michael; reveals him while he's invisible (watch for flickering street lights) |
| Flare gun | Blinds Michael |
| Pocket knife | Blinds/stuns Michael |
| Joint | Being high reveals sounds around you |
| Beer / drinks | Being drunk helps shake off fear |
| TV | Turned-on TVs create noise that can disorient Michael |
| Crowbar | Weapon — also breaks obstacles |
| Lock box code | Opens lock boxes, which usually contain weapons |

## Rules to remember

- **Phones need charisma**: calling the police is a timer mini-game, and low-charisma characters get very little out of it.
- **Escaping with a weapon removes it from the match** — drop spare weapons at the exit so NPCs and returning players can arm themselves.
- Items you drop are highlighted on the map for your team, but escape kits you find don't always show for them — call them out.
